# Identidade visual Tauge

Logotipos extraídos do arquivo fornecido pelo usuário, `Manual da marca - Tauge.pdf`:

- `tauge-logo.svg`: assinatura preferencial, página 1.
- `tauge-logo-light.svg`: aplicação em fundo azul, página 2.
- `tauge-symbol.svg`: símbolo da assinatura, página 1, usado também como favicon.

Os arquivos preservam o desenho original e suas proporções. A tipografia da
assinatura permanece nos contornos do logotipo; não foi substituída por texto.

Paleta web do manual: azul `#003C78`, ciano `#00CCFF`, verde `#85C226`.
Tons neutros e cores de estado complementam a interface para manter a leitura.

A interface usa Poppins Regular, Medium e SemiBold, hospedadas localmente em
`public/fonts`. Arquivos obtidos do repositório oficial
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/poppins), com a
licença original em `public/fonts/OFL.txt`.
